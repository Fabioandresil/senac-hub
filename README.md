# SENAC Hub

Vitrine de inovação para descobrir projetos criados por estudantes do SENAC.

## Como visualizar

Abra `index.html` no navegador. A página é estática e não precisa de instalação ou servidor.

## O que você encontra

- Projetos organizados por área de atuação.
- Busca por nome, descrição e palavras-chave.
- Filtros para explorar diferentes áreas.
- Layout responsivo para celular, tablet e desktop.

Os projetos exibidos são exemplos demonstrativos.
